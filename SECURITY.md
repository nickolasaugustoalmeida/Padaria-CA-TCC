# Política de segurança

## Versões suportadas

A branch `main` recebe correções de segurança.

## Relatando uma vulnerabilidade

Não abra uma issue pública com detalhes de uma vulnerabilidade. Use o recurso de relato privado de vulnerabilidades do GitHub, quando disponível, ou entre em contato de forma privada pelo perfil do mantenedor.

Inclua uma descrição do problema, os passos para reprodução, o possível impacto e, se houver, uma sugestão de correção. Evite anexar credenciais, dados pessoais ou informações reais de usuários.
